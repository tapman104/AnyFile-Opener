# 🌉 AnyFile Opener (OpenBridge)

**AnyFile Opener** is a lightweight Android utility for opening files with compatible apps, detecting file types using MIME types and binary signatures, and handling Android URI permissions.

## 🚀 Key Highlights

- **File Detection:** Identify file types using MIME types and magic bytes.
- **URI and Intent Handling:** Forward files to compatible apps with appropriate URI permissions.
- **Universal Handler:** Handle files when Android cannot find a suitable default app.
- **Binary Inspector:** View hex and ASCII previews of file headers.
- **Android/data Access:** Browse these folders through the system file picker where Android permits access.
- **Themes:** Material You and AMOLED Pure Black.
- **Recent Files and Widget:** Quick access to recent files and storage locations.
